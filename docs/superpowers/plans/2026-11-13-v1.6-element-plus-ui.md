> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 全部 5 视图迁移到 Element Plus 组件体系；暗色主题完善 + 手动主题切换开关；业务逻辑/后端/API 零改动。

**Spec:** 需求源 = 用户 2026-11-13："目前这个排版和界面整体比较丑 可以参考layui或者其他组件 重新优化下" + 2026-11-11"深色模式按钮对比度低"。选型决策由授权定夺：Element Plus（Vue3 生态成熟/暗色原生/迁移映射清晰；LayUI 原版 jQuery 系不匹配、layui-vue 小众）。
